# Expense Tracker

A beginner-friendly Python console application for managing personal expenses.

## Features

- Add expenses
- View expenses
- Search expenses by ID
- Delete expenses
- Input validation
- SQLite-based data persistence
- Automatic expense ID generation

## Technologies

- Python
- SQLite
- SQL

## How to Run

```bash
python3 expense_tracker.py
```

## Data Storage

Expenses are stored locally in `expenses.db` using SQLite.
